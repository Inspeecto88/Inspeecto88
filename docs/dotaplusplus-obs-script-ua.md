# Dotaplusplus — текст для запису в OBS (обличчя + розповідь), UA

Версія 2026-11-11. Формат: ти в кадрі (OBS, камера), поруч — вікно програми / гра.
Довжина: ~2 хв 30 с. З одного запису нарізаємо YouTube-відео і 4-5 шортів.
Читай звичайний текст. [У дужках] — що робиш, вголос не читати. `/` — коротка пауза, `//` — довга.

## Перед записом
- Сцена OBS: камера в куті (або на пів екрана) + захоплення екрана, 1920x1080, 60 fps.
- Світло: м'яке біле спереду, фон — фіолетові штори або білий ПК.
- Кожен блок — окремий дубль; помилився — пауза 2 с і блок спочатку (паузи виріже auto-editor).
- Говори як другу в Discord. Можна своїми словами, але порядок думок тримай.

### Блок 1. Хук [дивишся в камеру, близько]
Скільки ігор ти програв / ще до того, як почалася гра? //
Я граю на п'яти тисячах ММР / і скажу чесно: / половина програшів — це драфт. //
Сьогодні покажу, як закрити це однією клавішею.

### Блок 2. Хто я і чесність [в камеру]
Одразу прозоро: / я в команді проєкту Dotaplusplus / і отримую відсоток з підписок. //
Тому розкажу, що програма реально вміє, / і чого не вміє. / Вирішуєш ти.

### Блок 3. Що це [показуєш вікно програми]
Dotaplusplus — це програма для Windows, / яка дивиться на твій драфт / і підказує, кого пікати. //
Вона не грає за тебе / і нічого не натискає в грі. / Вона просто показує поради.

### Блок 4. F8 [драфт у грі, натискаєш F8]
Ось драфт. / Вороги вже пікнули. //
Тиснеш F8. //
Пів секунди — / і програма показує, / хто найкраще заходить проти саме цих героїв / і з твоїми союзниками. //
Раніше на це йшло чотири-вісім секунд, / зараз — майже миттєво.

### Блок 5. Три сортування [перемикаєш сортування]
Поради можна сортувати трьома способами. //
Перше — за шансом перемоги. / Просто: хто частіше виграє в такому драфті. //
Друге — контрпік і синергія. / Це коли пікаєш останнім / і хочеш покарати ворога. //
Третє — за лінією. / Для керрі й мідерів, / яким головне — виграти лайн. //
І важливо: / дані беруться під твій ранг, / а не з про-сцени.

### Блок 6. Механіка [драфт з Phoenix у ворогів]
А от що мені подобається найбільше. //
Програма пояснює не тільки цифрами, / а механікою. //
У ворогів Phoenix? / Troll і Snapfire / ламають його яйце. //
Huskar у міді? / Ancient Apparition — / і хіл йому не допоможе. //
Це речі, яких новачок не знає, / а на п'яти тисячах / вони вирішують файти.

### Блок 7. Предмети [пікнув героя, Ctrl+F8]
Героя пікнув — / тиснеш Ctrl+F8. //
І бачиш, що збирати / саме в цьому матчі, / а не той самий білд щогри.

### Блок 8. Налаштування [вікно налаштувань]
Що ще зручно. //
Є режими розпізнавання: / авто, / стадія піку / і гра. //
Зайві вкладки можна вимкнути, / а після десяти піків / вкладки драфту ховаються самі. //
І налаштування не злітають після оновлення.

### Блок 9. Чесно про мінуси [в камеру]
Тепер чесно. //
Програма не виграє гру за тебе. / Якщо ти не вмієш грати героєм, / ідеальний пік не врятує. //
Це підказка, / а рішення — / завжди твоє.

### Блок 10. CTA [в камеру]
Якщо хочеш спробувати — / посилання на Telegram у профілі / і в описі. //
Там завантаження, / [промокод: ____] / і розбори моїх драфтів. //
