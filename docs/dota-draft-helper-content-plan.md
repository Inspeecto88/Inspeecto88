# Draft Helper (Dota 2) — план контенту і сценарії

Чернетка v1, 2026-11-10. Джерело фактів: реліз v1.0.4 на GitHub (deltaonlyone/dota-draft-helper).
Все, що позначено [?], — треба підтвердити (див. питання в кінці).

## 1. Що за продукт (з релізу v1.0.4)

Десктоп-програма-порадник для драфту в Dota 2. Робить скріншот екрана, розпізнає пік і радить.

| Функція | Як показати в кадрі |
|---|---|
| F8 під час драфту — поради за ~0,5 с (раніше 4-8 с) | Таймер на екрані: натиснув F8 — поради з'явились |
| Ctrl+F8 — предмети для обраного героя | Пік героя -> Ctrl+F8 -> білд |
| «Кого пікати»: сортування за шансом перемоги / контрпік+синергія / лінія, дані під твій ранг | Перемкнути 3 сортування, показати як змінюється топ |
| Механічні контрпіки з поясненням (Troll і Snapfire ламають яйце Phoenix, AA проти Huskar) | Окремий short-факт |
| Режими розпізнавання: Авто / Стадія піку / Гра, профілі калібрування | Блок «налаштування» в довгому відео |
| Вкладки ховаються після 10 піків, можна вимкнути зайві | Коротко в довгому відео |
| Налаштування і кеш зберігаються після оновлення | Одне речення в кінці |

Дані, ймовірно, з STRATZ API [?] (статистика матчів Dota 2). Сайт stratz.com з цієї сесії недоступний,
тому деталі (який ранг, за який період) — питання до тебе.

## 2. Стратегія: одна зйомка — 4 платформи

- **Головна думка всієї серії:** «Драфт програють до хвилини 0:00. Ось як цього не робити».
- **Ціль контенту:** завантаження програми (посилання на реліз у профілі / опису) [?].
- **Аудиторія:** гравці Dota 2, які застрягли на ранзі і не знають мети; україномовні / СНД [?].
- **Схема:** знімаєш один раз сирий матеріал (розділ 3) -> монтуєш 1 довге відео YouTube (2-3 хв)
  + 4-6 коротких (45-60 с) для TikTok / Reels / Shorts з тих самих кадрів.

| Платформа | Формат | Довжина | Що важливо |
|---|---|---|---|
| YouTube | 16:9, гайд | 2-3 хв | Таймкоди, посилання на реліз в описі, закріплений коментар |
| YouTube Shorts | 9:16 | 45-60 с | Хук у 1 с, кінець «петлею» до початку |
| TikTok | 9:16 | 45-60 с | Хук + текст на екрані, трендовий звук тихо під голос |
| Instagram Reels | 9:16 | 30-60 с | Обкладинка з текстом, CTA «посилання в профілі», дубль у сторіс |

## 3. Що зняти (один знімальний день)

1. **Запис екрана (OBS, 1080p 60fps):**
   - 3-5 реальних драфтів з натисканням F8 (пиши кілька матчів, бери найнаочніший).
   - Ctrl+F8 на 2-3 героях.
   - Перемикання 3 сортувань «Кого пікати».
   - Встановлення з нуля: сторінка релізу -> завантаження -> перший запуск -> калібрування.
   - Пік проти Phoenix / Huskar, щоб показати механічні контрпіки.
   - Кінцевий екран перемоги (якщо була) з тим самим драфтом.
2. **Обличчя (телефон, вертикально + горизонтально):** реакції, «говоряча голова» для хуків і CTA.
3. **Руки/клавіатура крупно:** натискання F8 і Ctrl+F8 — 5-6 дублів (вставки на кожен short).
4. **Голос окремо** (петличка або телефон біля рота), щоб чисто накласти на запис екрана.

Важливо: OBS пише гру, а не оверлей? Перевір, що вікно програми потрапляє в запис (Display Capture).

## 7. Адаптація під платформи

- **TikTok:** голос + субтитри великим шрифтом, перші 2 с без логотипів; звук із трендів на 10-15% гучності.
- **Reels:** обкладинка з одним словом («F8», «PHOENIX»), той самий ролик, у сторіс — 15 с нарізка + стікер-посилання.
- **Shorts:** у назві ключ «Dota 2», без посилань у відео (не клікабельні) — веди на канал / закріплений коментар.
- **YouTube:** довге відео -> у кінці екран «дивись ще» на shorts-серію; shorts -> «повний гайд на каналі».

## 8. Ризик, який варто проговорити

Valve обмежує сторонні програми, що показують інформацію, якої немає в грі. Не обіцяй у роликах
«без бану / 100% безпечно», поки автор програми це не підтвердив. Формулювання «порадник для драфту
на основі статистики» — безпечне.
