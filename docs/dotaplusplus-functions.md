# Dotaplusplus (Draft Helper) — функціонал

Версія 2026-11-11. Джерело — офіційний опис релізу v1.0.4 на GitHub (deltaonlyone/dota-draft-helper).
Саму програму Claude не відкривав (немає доступу до ПК і файлів релізу), тому все з позначкою [?] —
перевір у програмі і виправ тут.

## Як це працює загалом
1. Програма запущена на Windows поруч із Dota 2.
2. Коли натискаєш гарячу клавішу, вона робить скріншот екрана і розпізнає, які герої вже на драфті.
3. Порівнює драфт зі статистикою матчів (ймовірно STRATZ [?]) під твій ранг і показує поради у своєму вікні.
4. Нічого не натискає за тебе в грі — тільки показує поради [?].

## Функції

| Функція | Як працює | Як показати в кадрі |
|---|---|---|
| **F8 — поради під час драфту** | Натискаєш F8 на стадії піку -> за ~0,5 с бачиш, кого пікати. Раніше було 4-8 с: порожні слоти більше не запускають повторне калібрування | Таймер на екрані: F8 -> поради |
| **Ctrl+F8 — предмети** | Для обраного героя показує, що збирати | Пікнув -> Ctrl+F8 -> білд |
| **«Кого пікати» — 3 сортування** | За шансом перемоги; за контрпіком і синергією; за виграшем на лінії. Дані під твій ранг | Перемкнути всі три, показати, як міняється топ |
| **Механічні контрпіки** | Пояснення, чому герой заходить: Troll і Snapfire ламають яйце Phoenix, Ancient Apparition проти Huskar | Драфт з Phoenix у ворогів |
| **Режими розпізнавання** | Перемикач Авто / Стадія піку / Гра біля кнопки скріншота; окремі профілі калібрування для піку і для гри | Налаштування |
| **Калібрування** | Налаштування розпізнавання під твій екран [?] | Встановлення |
| **Вкладки піку** | Після 10 піків ховаються самі; у налаштуваннях можна вимкнути будь-яку вкладку | Налаштування |
| **Предмети ворогів і союзників** | Окремі вкладки, які можна вимкнути [?] | Налаштування |
| **Швидкість** | Оновлюється тільки відкрита вкладка — дії майже миттєві | Загальне враження |
| **Збереження** | Налаштування й кеш не злітають після оновлення | Одне речення |
| **Стара комбінація** | F9 / Ctrl+F9 автоматично замінено на F8 / Ctrl+F8 | Не показувати |

## Що треба уточнити в програмі (5 хвилин)
1. Як виглядає головне вікно: окреме вікно чи поверх гри?
2. Скільки героїв у топі порад і що поруч із кожним (відсоток, пояснення)?
3. Чи є вхід / ліцензія / підписка всередині програми?
4. Чи є англійська мова інтерфейсу?
5. Звідки дані (STRATZ?) і за який період.
