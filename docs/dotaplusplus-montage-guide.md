# Dotaplusplus — як монтуємо відео

Версія 2026-11-11.

## Структура кожного короткого ролика (30-50 с)

| Блок | Час | Що в кадрі | Звідки |
|---|---|---|---|
| Хук | 0-3 с | Ти в сетапі дивишся в камеру + великий текст угорі | Твоя зйомка або Kling (ти у своїй кімнаті) |
| Проблема | 3-6 с | Сетап / драфт, де ворог уже пікнув | Kling-кліп ПК або запис екрана |
| Демо F8 | 6-15 с | Запис екрана: драфт -> F8 -> поради; зум на топ-3 | Твій запис OBS |
| Сортування і механіка | 15-22 с | Перемикання сортувань, порада Troll vs Phoenix | Запис OBS |
| Предмети | 22-26 с | Ctrl+F8 -> білд | Запис OBS |
| CTA | 26-32 с | Ти в кадрі + DOTAPLUSPLUS + «Telegram — посилання в профілі» | Твоя зйомка / Kling |

Правила: новий кадр кожні 2-4 с; без логотипів у перші 2 с; кінець візуально схожий на початок (петля).

## Налаштування

| Параметр | Значення |
|---|---|
| Формат | 1080x1920, 9:16, 30 fps, H.264, звук AAC |
| Запис екрана | OBS: 1920x1080, 60 fps, Display Capture (щоб вікно програми теж писалось), CRF/CQP 18-20 |
| Кроп запису | Вирізаємо зону драфту/вікна програми і масштабуємо на всю висоту, без чорних смуг |
| Субтитри | Inter ExtraBold 86 px, білі, темна обводка 7 px, акцент #8B3DFF, нижня третина (відступ ~560 px знизу) |
| Хук-текст | 104 px, угорі (відступ ~260 px), 2-3 рядки максимум |
| Позначка реклами | Дрібно, лівий верхній кут, весь ролик |
| Звук | Голос -6 dB, музика -20 dB під голосом; клік на F8; без музики з авторськими правами у файлі — трендовий звук додаєш у самому TikTok |
| Безпечні зони | Не ставити текст у нижні ~350 px і праві ~150 px — там кнопки TikTok/Reels |

## Як зібрати (автоматично)

```bash
cd content/dotaplusplus/test-video
```

```bash
bash build.sh ua
```

```bash
bash build.sh en
```

Поклади свої записи екрана в `content/dotaplusplus/test-video/rec/` як `screen1.mp4` (F8), `screen2.mp4` (сортування і механіка),
`screen3.mp4` (Ctrl+F8) — скрипт сам поставить їх замість заглушок. Голос додаємо наступним кроком (озвучку UA читаєш ти з
`docs/dotaplusplus-teleprompter-ua.md`; EN — TikTok text-to-speech або AI-голос).

## Якщо монтуєш у CapCut сам
1. Новий проєкт 9:16, 1080p, 30 fps.
2. Доріжка 1: кліпи за таблицею вище. Доріжка 2: субтитри (Автосубтитри -> виправити -> шрифт жирний, білий, обводка, ключові слова фіолетові).
3. Хук-текст окремим текстовим шаром угорі на 0-3 с.
4. Зум 105-110% на важливих моментах запису екрана (ключові кадри).
5. Експорт 1080p, 30 fps, високий бітрейт.
