# Dotaplusplus — план контенту і сценарії

Чернетка v2, 2026-11-10. Продукт: Dotaplusplus (у релізах на GitHub поки називається Draft Helper, v1.0.4).
Англійський пакет — окремим файлом: `docs/dotaplusplus-en-pack.md`.
Все з позначкою [?] треба підтвердити (питання в кінці).

## 1. Вихідні дані

| Що | Відповідь |
|---|---|
| Продукт | Dotaplusplus — порадник драфту і предметів для Dota 2, Windows |
| Модель | Підписка (ціна, пробний період [?]) |
| Моя роль | Команда просування, % від підписок |

## 2. Що вміє продукт (з релізу v1.0.4)

| Функція | Як показати в кадрі |
|---|---|
| F8 під час драфту — поради за ~0,5 с | Таймер: натиснув F8 — поради з'явились |
| Ctrl+F8 — предмети для обраного героя | Пік героя -> Ctrl+F8 -> білд |
| «Кого пікати»: сортування за шансом перемоги / контрпік+синергія / лінія, дані під твій ранг | Перемкнути 3 сортування, показати як змінюється топ |
| Механічні контрпіки з поясненням (Troll і Snapfire ламають яйце Phoenix, AA проти Huskar) | Окремий short-факт |
| Режими розпізнавання Авто / Стадія піку / Гра, профілі калібрування | Блок «налаштування» в довгому відео |
| Вкладки ховаються після 10 піків, зайві можна вимкнути | Коротко в довгому відео |
| Налаштування й кеш зберігаються після оновлення | Одне речення |

## 3. Обов'язково: позначка реклами

Ти отримуєш % від підписок — це комерційний контент. Без позначки платформи ріжуть охоплення
або видаляють відео, а глядачі, які дізнаються пізніше, перестають довіряти.
- **TikTok:** перемикач «Розкриття інформації про контент» при публікації (власний бренд / брендований контент).
- **Instagram:** позначка «Партнерство» або чесно в тексті: «Я в команді Dotaplusplus».
- **YouTube:** галочка «Містить платне просування».
- **У кадрі одне речення:** «Я в команді проєкту, тому скажу чесно, що він вміє, а що ні.» —
  це ще й підвищує довіру.

Також не обіцяй «без бану / 100% безпечно», поки автор не підтвердив позицію щодо правил Valve.
Безпечне формулювання: «порадник для драфту на основі статистики матчів».

## 4. Воронка: відео -> Telegram -> підписка

1. Відео дає одну корисну думку + показ програми.
2. CTA завжди один: «Telegram-канал — посилання в профілі» (або назва каналу текстом на екрані
   і в закріпленому коментарі, якщо посилання в профілі ще недоступне).
3. У Telegram: закріплений пост (нижче) -> посилання на завантаження -> підписка.
4. Що давати в Telegram, щоб люди лишались: розбори драфтів з твоїх ігор, оновлення програми,
   контрпік дня.

## 5. Знімальний день (UA)

1. **Запис екрана OBS (1080p 60fps, Display Capture, щоб вікно програми теж писалось):**
   3-5 драфтів з F8; Ctrl+F8 на 2-3 героях; 3 сортування; встановлення з нуля;
   пік проти Phoenix / Huskar; екран перемоги з тим самим драфтом.
2. **Ти в кадрі (телефон, 9:16 і 16:9):** хуки, CTA, реакції. Фон — твій ігровий сетап.
3. **Руки на клавіатурі крупно:** F8 і Ctrl+F8, 5-6 дублів.
4. **Голос окремо** (петличка) для накладання на запис екрана.
5. **Скріншот рангу 5k** — для кредиту довіри на 1-2 с.

Ці ж записи екрана йдуть і в англійський пакет — знімай з запасом.
